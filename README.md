# 🎬 Задание 4: Создание мультимедийного ролика с визуализацией на основе музыки

Этот репозиторий содержит материалы, промпты и исходные файлы для выполнения практического задания по генерации мультимедийного контента с помощью ИИ.

## 🎯 1. Описание идеи
- **Тема:** Путешествие по магической библиотеке.
- **О чём ролик:** Старинная книга со светящейся надписью самопроизвольно раскрывается, выпуская вихрь золотых частиц.
- **Настроение:** Вдохновляющее, загадочное, кинематографичное.

## 🛠 2. Использованные инструменты
- **Музыка:** [Suno AI](https://suno.com/)
- **Изображения:** [Ideogram.ai](https://ideogram.ai/), [Шедеврум](https://shedevrum.ai/)
- **Анимация:** [Kling AI](https://klingai.com/)
- **Монтаж:** CapCut
